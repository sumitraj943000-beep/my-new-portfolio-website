# Sumit Raj Portfolio

A responsive personal portfolio for student profile + career growth.

## Files
- index.html — main website
- style.css — responsive design
- script.js — mobile menu + scroll animations

## Customize
1. Replace the YOUR PHOTO placeholder in index.html with your photo.
2. Update the Education entries with your exact institution details.
3. Add real project links and certificate images.
4. Change social links if needed.
5. Upload the three files to GitHub Pages, Netlify, Vercel, or another static host.

## Canva version
Use the same structure:
Home → About → Education → Skills → Projects → Achievements → Career Journey → Gallery → Contact.
